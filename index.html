How to Use the Suggestion

The app compares how closely each curve follows the historical observations. A lower RMSE means smaller average prediction error on the entered historical data, so that model is suggested as the closer data fit. For presentation, compare the graph, equation and RMSE before choosing which model to demonstrate.
