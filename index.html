Formulas used

Normal Distribution

f(x) = 1 / (σ√(2π)) · e^[-(x−μ)²/(2σ²)] Z = (x − μ) / σ P(X ≤ x) = Φ(Z)

Poisson Distribution

P(X = k) = e^(−λ) λ^k / k! λ = average requests per fixed interval k = observed/request-count value
